# 🎮 Простой Telegram Clicker (Mini App + Stars)

Готовый кликер, который можно запустить за 15–20 минут.

## Что умеет

- Тапать и зарабатывать очки
- Энергия (регенерируется сама)
- Уровни и сила клика
- Покупки за очки (+сила, восстановить энергию)
- Покупки за **Telegram Stars**:
  - x2 буст на 1 час — 50 ⭐
  - +50 к максимуму энергии — 100 ⭐

## Быстрый запуск

### 1. Создай бота
1. Открой [@BotFather](https://t.me/BotFather)
2. `/newbot` → придумай имя и username
3. Скопируй **токен** (выглядит как `7123456789:AAH...`)

### 2. Создай Mini App
В @BotFather:
```
/newapp
```
- Выбери своего бота
- Название: `Clicker`
- Описание: любое
- Картинку можно пропустить
- **Web App URL** — пока поставь любой (например `https://example.com`), потом поменяем

### 3. Залей проект

#### Вариант А — Railway (самый простой)
1. Зайди на [railway.app](https://railway.app)
2. New Project → Deploy from GitHub (или загрузи папку)
3. Добавь переменную окружения:
   ```
   BOT_TOKEN = твой_токен_от_BotFather
   ```
4. После деплоя скопируй ссылку вида `https://xxx.up.railway.app`

#### Вариант Б — локально (для теста)
```bash
cd telegram-clicker
npm install
BOT_TOKEN=твой_токен npm start
```
Потом пробрось через ngrok:
```bash
ngrok http 3000
```

### 4. Привяжи ссылку к боту
1. @BotFather → `/myapps`
2. Выбери приложение
3. Edit Web App URL → вставь ссылку с Railway / ngrok
4. Также можно поставить кнопку меню:
   - `/mybots` → Bot Settings → Menu Button → Edit Menu Button URL

### 5. Настрой Webhook (чтобы платежи работали)

После деплоя выполни один раз (подставь свои данные):

```bash
curl "https://api.telegram.org/botТВОЙ_ТОКЕН/setWebhook?url=https://ТВОЙ_ДОМЕН/webhook/ТВОЙ_ТОКЕН"
```

### 6. Готово!
Открой бота в Telegram и нажми кнопку меню / ссылку Mini App.
